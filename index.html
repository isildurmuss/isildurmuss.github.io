Story

I'm Isil, a Geomatics Engineering graduate from Istanbul Technical University, and a GeoAI developer focused on spatial data. Throughout my studies I focused on building fully autonomous, intelligent system architectures using the Python, FastAPI and Docker ecosystem.

Among the projects I've built are an autonomous GIS agent platform orchestrating 7 different LLMs simultaneously, a natural-language-powered smart data query engine (GeoChat/RAG), and reinforcement-learning-based (Q-Learning) robotic route optimization simulations.

My engineering internship at the General Directorate of Mapping (Ministry of National Defense) instilled a discipline for data accuracy that I now carry into autonomous, intelligent GIS projects that push the boundaries of what AI can do spatially.

Projects
2025
GIS Agent Console — GeoAI-Powered Automation of GIS Workflows (Capstone Project)
Completed

An end-to-end web platform letting users run spatial queries in plain natural language, with no need to know GIS command syntax. Built on a Python/FastAPI backend with an asyncio architecture, it routes queries through n8n automation webhooks to 7 different LLMs simultaneously (Claude, GPT, Llama, Gemini, DeepSeek, Qwen, GLM). Results are rendered in real time as dynamic GeoJSON layers via Maplibre.js. The core scientific contribution is GeoBenchX, an evaluation framework I designed to score each model's GIS capability from 0-2 against manual ArcGIS Pro ground-truth references.

2024
GeoChat — Hybrid Search & NLP-Powered Spatial Decision Support System
Completed

Modeled Istanbul public transport data from the IBB open data portal in Supabase (PostgreSQL), then used the Groq API to convert users' natural language questions into SQL queries on the fly. The system first queries the local database, and falls back to the model's own knowledge when the detail isn't available — producing a decision-support mechanism that always responds.

2024
EV Charging Station Accessibility & Site Selection Analysis in Istanbul
Completed

Team project combining GIS with Multi-Criteria Decision Analysis (MCDA) to support Istanbul's EV infrastructure transition. Weighted 8 social, economic and physical criteria from survey data using Fuzzy Analytic Hierarchy Process (FAHP) to build spatial suitability models, identifying strategic locations that optimize investment cost and network efficiency.

2025 — Ongoing
GeoAI-Based Telecom Infrastructure Optimization
In Progress

A two-module FastAPI + Streamlit web app to optimize decision-support in telecom infrastructure projects. Module one processes OpenStreetMap data with Dijkstra's algorithm for cost- and distance-optimal fiber routing, backed by building-density ROI models. Module two uses a grid-based scoring algorithm to determine the most efficient base station locations. Currently working on Docker containerization and algorithm performance tuning for deployment.

2023
Geometric Algorithms vs. Q-Learning in Robotic Motion Planning & Obstacle Awareness
Completed

Comparative study of classical geometric algorithms against reinforcement learning (Q-Learning) for robotic motion planning. Built a grid-based environment from a floor plan and evaluated A*, Dijkstra and RRT algorithms against a Q-Learning model on obstacle awareness and route optimization performance.
